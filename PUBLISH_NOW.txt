========================================
TROUBLESHOOTING
========================================

Error: "Repository not found"
   → Ensure repository exists on GitHub
   → Check you're using correct username
   → Verify remote URL is correct

Error: "Remote contains work you don't have"
   → Run: git pull origin main --allow-unrelated-histories
   → Then: git push -u origin main

Error: "Authentication failed"
   → Use PAT (Personal Access Token), not password
   → Create new PAT at github.com/settings/tokens

Error: "Permission denied"
   → Check you have write access to repository
   → Verify you're logged into correct GitHub account
